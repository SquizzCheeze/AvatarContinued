Avatar Changelog Archive
========================

Shipped versions before the current one. The packager reads changelog.txt
verbatim (see manual-changelog in .pkgmeta), so that file holds only the
version being built -- otherwise every CurseForge release reposts the whole
history as its release notes. Older sections move here instead of being
deleted. This file is in the .pkgmeta ignore list, so it never ships.

The sections below are the original Avatar addon's history, from before it
was revived as Avatar Continued.


3.0.0

- Updated for Battle for Azeroth.
- Added support for new allied races: Dark Iron Dwarf and Mag'har Orc.

2.0.2

- Added allied race visual offsets and toggles.

2.0.1

- TOC bump for patch 7.3.0.
- Removed PlaySound from options opening.

2.0.0

- Legion update.
  - Updated to support new transmog API.
  - Removed gear visual options because with the new API the addon can now
    receive proper item visuals.
