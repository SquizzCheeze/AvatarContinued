Avatar Changelog Archive
========================

Shipped versions before the current one. The packager reads changelog.txt
verbatim (see manual-changelog in .pkgmeta), so that file holds only the
version being built -- otherwise every CurseForge release reposts the whole
history as its release notes. Older sections move here instead of being
deleted. This file is in the .pkgmeta ignore list, so it never ships.

Avatar Continued 1.0 to 1.6 shipped before this repository existed and have no
notes here.

V1.9 (2026-09-16)

Added:

- "/rl" as a shortcut for reloading your interface, the same as /reload. It is
  only claimed if no other addon already provides it, so an existing one keeps
  working.

Changed:

- Declares support for patch 12.1.5 alongside 12.1.0, so it loads on the
  12.1.5 test client without being marked out of date.

V1.8 (2026-09-14)

Fixed:

- When Avatar Continued updated at the same login as SquizzFrames or
  Squizzumables, their update notes drew on top of each other and flickered.
  They now appear one after another: close one and the next opens.


V1.7 (2026-09-14)

New:

- A short note about what changed now appears once after each update, and a
  welcome note on first install. Type /avatar notes to see it again.

Fixed:

- Clicking either light colour swatch in the settings window threw an error.

- "Hide Avatar in Combat" did nothing. The avatar now hides when combat starts
  and comes back when it ends.

- Creating a profile errored when you clicked Create (pressing Enter worked).

- "Delete Current" never deleted the profile, and its confirmation popup
  errored as it opened.

- Visiting Avatar Continued under Options > AddOns broke the settings window:
  afterwards, /avatar opened a window that was nowhere to be seen. That entry
  is now a small page with a button that opens the real window.

- Opening the settings window could quietly change your saved settings,
  rounding them to the nearest slider step. Avatar facing was the one most
  likely to shift.

- "/avatar profile Name" created a new, lower-cased profile instead of
  switching to the one you named.

- "/avatar equip" errored when given a plain item ID.

Changed:

- The settings window's dropdowns now use the game's current dropdown menus.
